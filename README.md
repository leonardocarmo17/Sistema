# Sistema

Este projeto possui três categorias de usuários, cada uma com diferentes níveis de permissão: **Usuário**, **Admin** e **Dono**.

---

## Categorias de Usuários

### Usuário
- **Cadastro**: Inclui nome, sobrenome, e-mail, senha, data de nascimento e foto (opcional).
- **Acesso**: Para acessar o sistema, é necessário verificar o e-mail e confirmar a conta. Caso contrário, o acesso será bloqueado.
- **Painel do Usuário**: É possível alterar os próprios dados, com exceção do e-mail, que não pode ser modificado após o cadastro.

### Admin
- **Permissões**: Podem gerenciar as informações dos usuários, exceto os campos de cargo e senha.
- **Privacidade**: Admins Secundários podem visualizar os dados, mas o campo de senha aparecerá oculto.

### Dono
- **Permissões**: Tem controle total sobre o sistema e pode modificar qualquer informação de qualquer usuário, incluindo Admins Secundários.

---

## Regras Gerais

- Todos os usuários, incluindo administradores, podem alterar seus próprios dados na página inicial, exceto o e-mail, que não pode ser alterado após o cadastro.
- Em caso de esquecimento da senha, há uma opção de recuperação na página de login. Ao informar o e-mail cadastrado, o sistema enviará uma nova senha criptografada, garantindo a segurança dos dados.
